# Synthetic demonstration data

`synthetic_orbit_users.csv` contains 2,400 fictional behavioural snapshots generated with seed 2026. It is **not** organizer data, AstroLive customer data, measured performance, or evidence of product impact. It has no names, contact details, birth data, concerns/free text, or real account identifiers.

Reproduce it from the repository root:

```bash
python scripts/generate_demo_data.py
```

The full field audit, target balance, leakage review, limitations, and responsible-use constraints are in `docs/DATA_AUDIT.md`.
